# 공용 예약

상담실과 차량을 **달력**에서 예약하는 직원용 웹앱입니다.
달력에서 날짜를 누르면 그날 시간표(1시간 단위)가 열리고, 빈칸(+)을 눌러 예약합니다.
**센터일정** 탭에는 회의·행사 같은 센터 일정을 날짜별로 적어 함께 봅니다. (같은 날 여러 개, 종일도 됩니다)

[wisdomheo/room-booking](https://github.com/wisdomheo/room-booking)(상담실 예약)을 참고해 만들었습니다.
두 앱은 서로의 예약을 모릅니다. 같은 상담실을 두 앱에서 함께 받으면 겹칠 수 있으니 한쪽으로 정해서 씁니다.

## 지금은 체험 모드

`config.js`의 `API_URL`이 비어 있으면 체험 모드입니다. 예약은 그 기기에만 저장되고 다른 직원에게 보이지 않습니다.
직원끼리 같은 시간표를 보려면 아래처럼 구글 시트를 한 번 연결합니다.

## 직원끼리 함께 쓰기 (구글 시트 연결, 처음 한 번)

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만듭니다. (이름 예: 공용 예약)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 처음 보이는 `Code.gs`의 내용을 모두 지우고 [server/Code.gs](server/Code.gs) 내용을 붙여 넣습니다.
4. 왼쪽 **파일 옆 +** → **스크립트** → 이름을 `core`로 하고 [js/core.js](js/core.js) 내용을 붙여 넣습니다.
5. 💾 저장 → 위쪽 함수 목록에서 `setup`을 고르고 **실행** → 권한을 허용합니다.
   시트에 **직원·항목·예약·일정·기록** 탭이 생깁니다. 처음 있던 '시트1'은 지워도 됩니다.
6. **직원** 탭: A열에 직원 이름을 적고, 관리자는 B열(관리자) 칸을 체크합니다.
7. **항목** 탭: 상담실1·상담실2·상담실3·집단상담실·차량이 들어 있습니다. 이름은 고쳐도 되고(예: 차량 → 차종), 더 있으면 아래 줄에 적습니다.
   분류는 **상담실·차량·검사도구** 중에서 고릅니다. 검사도구 줄을 적으면 화면에 그 탭이 생깁니다.
   C열 코드는 서버가 채우니 비워 둡니다. 시간표의 칸 순서는 이 탭의 줄 순서를 따릅니다.
8. Apps Script에서 **배포 → 새 배포 → 유형 선택(톱니) → 웹 앱**을 고르고
   실행 사용자 **나**, 액세스 권한 **모든 사용자**로 배포합니다. 나온 **웹 앱 URL**(`…/exec`)을 복사합니다.
   이 주소를 브라우저로 열어 "공용 예약 서버가 동작하고 있어요."가 보이면 맞게 된 것입니다.
9. 이 저장소의 `config.js`를 열어 연필(✏️)로 고치기 → `API_URL: ''`의 따옴표 안에 주소를 붙여 넣고 **Commit changes**를 누릅니다.
10. 1~2분 뒤 사이트를 새로 고치면 '체험 모드' 표시가 사라집니다. 직원은 처음 들어올 때 자기 이름을 고르고 비밀번호 4자리를 정합니다.

## 알아 둘 것

- 비밀번호를 5번 틀리면 잠깁니다. 관리자가 앱 메뉴의 **직원 비밀번호 초기화**로 풉니다.
- 관리자가 다른 사람의 예약을 바꾸거나 취소하면 **기록** 탭에 남습니다.
- 센터일정은 직원 누구나 넣고, 넣은 사람과 관리자만 바꾸거나 지울 수 있습니다. (관리자가 남의 일정을 고쳐도 기록 탭에 남습니다)
- 항목 이름은 언제 고쳐도 예약이 이어집니다. 항목 줄을 지우면 그 항목의 예약도 시간표에서 사라집니다.
- 직원이 그만두면 직원 탭에서 그 줄을 지웁니다. 그 사람의 로그인도 바로 끊깁니다.
- 내담자 이름·학교명·연락처는 적지 않습니다. 용도는 정해진 낱말 중에서만 고릅니다.

## 코드를 고칠 때

- `js/core.js`(예약 규칙)를 고치면 Apps Script의 `core`에도 다시 붙여 넣고
  **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 서버에도 반영됩니다. (주소는 그대로입니다)
- 화면 파일을 고치면 `sw.js`의 `VERSION`을 올려야 휴대폰에 설치한 앱도 새 파일을 받습니다.
- 규칙·서버 점검: `node server/test.js` (구글 시트를 흉내 낸 가짜 시트에서 돌려 봅니다)
